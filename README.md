# 🐍 Интенсив по Tkinter: 4 дня создания GUI-приложений  

## 📌 Что это?

Набор учебных проектов, выполненных в рамках 4-дневного интенсива по Tkinter — встроенной библиотеке Python для создания графических интерфейсов.
Каждый день посвящён новым виджетам и возможностям, а также завершается практическим проектом.

## 📁 Структура проекта

Проекты и учебные материалы разбиты по дням и находятся в отдельных папках:

```
Day 1/
Day 2/
Day 3/
Day 4/
```

В каждой папке вы найдёте:
+ 🧠 Обучающие файлы с примерами работы с виджетами;
+ 🛠 Полноценные мини-проекты, созданные на основе изученного материала;
+ 📽 Презентации с краткой теорией и визуальными подсказками.

# 📚 Изученные темы по дням

## 📅 День 1: Основы Tkinter

Выученные виджеты и методы:
+ `Label` — текстовые надписи
+ `Button` — кнопки
+ `command` — обработка нажатий

🧩 Проект:  
✅ Кликер со статистикой — простое приложение, считающее количество кликов и отображающее результат.

## 📅 День 2: Поля ввода и размещение

Выученные темы:
+ Слои размещения: `pack`, `grid`, `place`
+ `Entry` — поле ввода текста
+ `.destroy()` — удаление элементов

🧩 Проект:  
✅ Приложение обратной связи — форма, собирающая данные пользователя.

## 📅 День 3: Переключатели и стилизация

Выученные виджеты и концепции:
+ `Checkbutton` — флажки
+ `Radiobutton` — переключатели
+ `style` — кастомизация стилей через словари
+ `IntVar`, `StringVar`, и другие переменные Tkinter

🧩 Проект:  
✅ Улучшенная форма обратной связи — с возможностью выбора вариантов и расширенной логикой.

## 📅 День 4: Графика  

Выученные библиотеки и виджеты:
+ Работа с изображениями (`PhotoImage`)
+ Использование библиотеки `PIL` (Pillow) с Tkinter
+ Библиотека `ttk` для более современного интерфейса

🧩 Проекты:
+ ✅ Просмотрщик мемов — приложение с переключением изображений
+ ✅ Версия проекта из Дня 3 с использованием `ttk` — стилизованная форма
